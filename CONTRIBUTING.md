# Contributing to Inex's GPT Image 2 Prompts

Thanks for wanting to contribute! This guide explains how to add a new prompt to the collection.

## 📋 Quick Checklist

Before opening a PR, make sure your contribution meets all of these:

- [ ] The image was actually generated by **GPT Image 2** (not DALL-E 3, Midjourney, etc.)
- [ ] The image is optimized (WebP or JPG, max 1024px on the long side, ~85 quality)
- [ ] The image filename is descriptive and kebab-case (`cyberpunk-neon-portrait-001.webp`)
- [ ] The image is placed in the correct category folder under `assets/images/`
- [ ] The README entry follows the [standard template](#prompt-template)
- [ ] The "Why it works" section explains a concrete prompting technique
- [ ] The prompt is in **English** (this is the contribution language for this repo)
- [ ] No copyrighted characters, real public figures, or branded IP in the output

## 🖼️ Image Requirements

**Format:** WebP preferred (smaller files), JPG accepted. Avoid PNG unless the image truly needs transparency.

**Dimensions:** Max 1024×1024px. Larger images bloat the repo and slow down clones.

**Quality:** Around 85 for WebP/JPG. Higher is wasteful; lower starts to show artifacts.

**Optimization script:** If you have ImageMagick installed, you can use the helper:

```bash
./scripts/optimize.sh path/to/raw-image.png assets/images/portraits/your-name-001.webp
```

**Filename convention:** `<topic>-<descriptor>-<number>.webp`
- ✅ `cyberpunk-neon-portrait-001.webp`
- ✅ `vintage-travel-poster-mars-002.webp`
- ❌ `IMG_2847.PNG`
- ❌ `My Cool Image (final) (1).png`

## 📝 Prompt Template

Copy this block, fill it in, and paste it into the appropriate category section of `README.md`:

````markdown
#### Your Prompt Title Here

<img src="./assets/images/<category>/<filename>.webp" width="600" alt="Short alt text describing the image">

**Category:** <Category> · **Tags:** `tag1` `tag2` `tag3`

<details>
<summary>📋 Full prompt (click to copy)</summary>

```
The complete prompt text, exactly as you sent it to GPT Image 2.
Keep formatting (line breaks, commas) so it can be copied verbatim.
```

</details>

**💡 Why it works:** One or two sentences explaining the *technique* — what about the prompt structure makes GPT Image 2 produce a good result. Don't just describe the image; explain the prompting engineering.

**🔧 Variations:** Concrete swaps a reader can make to adapt the prompt (one or two changes max).

---
````

## 🏷️ Categories

Use one of these existing categories, or propose a new one in your PR description:

| Category | Folder | What goes here |
|---|---|---|
| 🖼️ Portraits | `portraits/` | People, faces, character shots |
| 🔤 Text Rendering | `text-rendering/` | Prompts where rendered text is the centerpiece |
| 🎭 Commercial Illustration | `illustrations/` | Editorial, marketing, book-cover style art |
| 📦 Product & Mockups | `product/` | Product shots, packaging, mockups |
| 🏷️ Logos & Branding | `logos/` | Logo concepts, brand marks, typography systems |
| 🌆 Scenes & Environments | `scenes/` | Landscapes, interiors, world-building |

If your prompt clearly fits a new category that several future contributions could also use, propose it. One-off categories will be rejected; better to fit into an existing one.

## ✍️ Writing Good "Why it works" Notes

This is the section that makes this repo valuable. A weak note just describes the output:

> ❌ "This creates a beautiful cyberpunk portrait with neon colors."

A strong note explains the *technique*:

> ✅ "GPT Image 2 nails the word 'FUTURE' because it's short, uppercase, and has an explicit position ('across her cheek'). Without these three anchors, text rendering accuracy drops significantly."

Try to call out at least one of:

- A specific word, phrase, or structural choice that improved the output
- A common failure mode this prompt avoids
- A trick about ordering, hierarchy, or anchoring
- A reference (artist, era, medium) that locks in style

## 🚫 What Gets Rejected

- Prompts generating copyrighted characters (Disney, Marvel, Nintendo, etc.)
- Prompts depicting real, identifiable public figures
- NSFW, gore, or otherwise harmful content
- Output from models other than GPT Image 2
- Entries without a substantive "Why it works" section
- Images larger than 1024px or in unoptimized formats
- Duplicates of existing prompts with only minor variations

## 🔄 The PR Process

1. Fork the repo
2. Create a branch: `git checkout -b add-cyberpunk-portrait`
3. Add your image and README entry
4. Commit with a clear message: `git commit -m "Add cyberpunk neon portrait prompt"`
5. Push and open a PR against `main`
6. In the PR description, paste a screenshot of how your entry renders on GitHub

PRs are reviewed for: image quality, prompt accuracy, "why it works" usefulness, and adherence to the template.
